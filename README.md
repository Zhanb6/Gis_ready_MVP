# AstanaHub Logistics MVP

Локальный MVP веб-платформы автоматизации заявок, согласования и месячного планирования перевозок.

## Запуск в локальной сети

```bash
node tools/generate_env.js
docker compose up -d --build
```

Команда генерации создаёт локальный `.env` с уникальными логинами и длинными случайными паролями. Файл исключён из Git. Учётные данные начальных ролей смотрите только в своём локальном `.env` и передавайте пользователям безопасным каналом.

На сервере приложение доступно на `http://localhost:3000`, а другим компьютерам локальной сети — по адресу `http://IP_СЕРВЕРА:3000`, например `http://10.18.2.54:3000`.

Полная инструкция по IP-адресу, закрытой установке, firewall, общей базе и диагностике: [docs/LAN_DEPLOYMENT.md](docs/LAN_DEPLOYMENT.md).

## Offline-ограничение

Приложение не использует CDN, внешние карты, внешние шрифты или облачные API. Приложение, PostgreSQL и Ollama находятся во внутренней Docker-сети и не публикуют порты; наружу открыт только минимальный LAN-шлюз на порту `3000`. Все пользователи работают с одной PostgreSQL в volume `postgres-data`.

## Безопасность перед публикацией

- не добавляйте `.env`, дампы PostgreSQL, сертификаты и приватные ключи в Git;
- пароли пользователей хранятся в PostgreSQL только как `scrypt`-хэши с индивидуальной солью;
- после пяти неудачных попыток вход блокируется на 15 минут;
- сессия действует не более 8 часов, cookie имеет `HttpOnly` и `SameSite=Strict`;
- для развёртывания за HTTPS установите `COOKIE_SECURE=true`;
- дополнительные правила находятся в [SECURITY.md](SECURITY.md).

Перед `git add` и `git push` выполните:

```bash
npm run security-check
```

## MVP-ограничения текущей реализации

- Все рабочие данные хранятся только в общей PostgreSQL.
- Excel пока представлен CSV-экспортом, совместимым с табличными редакторами.
- PDF пока представлен печатной HTML-формой через кнопку "Печать / сохранить в PDF".
- Утвержденные Excel/PDF-шаблоны "пиксель-в-пиксель" нужно подключить после получения официальных форм.
- Справочники, тарифы, расстояния и права ролей являются временными MVP-допущениями.
- Если расстояние для маршрута отсутствует, черновик сохраняется, но расчет показывает ошибку, а отправка дальше по workflow блокируется до заполнения матрицы расстояний.
- Целевой минимум браузеров: Chrome 70+ и Firefox ESR. IE11 не поддерживается.
